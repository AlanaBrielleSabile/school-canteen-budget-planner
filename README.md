# School Canteen Budget Planner 

Project Description 
- The School Canteen Budget Planner is a proposed program that will help students plan their canteen purchases based on their available daily budget.
- The program will allow users to enter their budget and planned food or drink items with their prices. It will then calculate the total planned cost, remaining balance, and whether the purchase is within budget.

Project Status
- This project is currently in the proposal and planning stage. The actual program will be developed in a future stage.
